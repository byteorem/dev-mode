# figure-it-out

Produces: an approved plan, then the work.

For work no playbook fits, or that is large, cross-repo, or long-running.

1. Done predicate: one falsifiable statement of what is true when finished.
2. Rigor scaled to blast radius. More reach means more checks.
3. Harness first: how each step will be verified, before any work.
4. Steps written. Show them and get approval.
5. Run them. On long or unattended runs, log each decision (time, decision, why, evidence) on the task or in a scratch file.
6. If this shape of work recurs, propose it as a new playbook.

Reply: the done predicate, whether it holds, the evidence, and decisions worth reviewing.
