# investigate

Produces: a cited answer. No code changes.

1. Restate the question in one line. "How does this work" goes to `how`. "Why is it like this" goes to `why`. Some need both.
2. Answer from evidence: file:line, commit, PR, ticket, or a query result the user ran. Label anything inferred.
3. Data needed → write the query for the user to run and wait for the result.
4. Stop at the answer. Bugs or risks found along the way become candidate tasks. Don't start them.

Reply: the answer first, then evidence, open questions, and candidate follow-ups.
