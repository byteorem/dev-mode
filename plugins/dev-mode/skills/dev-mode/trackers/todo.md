# Tracker: todo

The session todo list, for repos with no `## dev-mode` block. Nothing outlives the session, so say so when creating a task.

## Create

The task title as one todo item, with its acceptance criteria as items under it. The body stays in the chat.

## Read

The todo list and the conversation.

## List

The todo list.

## Claim

Mark the item in progress.

## Note

Say it in the chat.

## Split

One item per slice in blocker order, naming its blockers in the item text.

## Set state

No states. `triage` needs a tracker that persists, so it gives the brief or questions in its reply instead.

## Close

Mark the item completed.
