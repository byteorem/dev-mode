# Encode Lessons in Structure

Put the lesson where it gets enforced, not just remembered: a check, a script, a test, a skill edit.

**Why:** text is the weakest enforcement. A note gets skipped; a failing check doesn't.

**Pattern:** strongest home first. Test or check, then script, then skill step, then a line in CLAUDE.local.md.

**Anti-patterns:** "I'll remember next time"; adding a paragraph when a check would do.
