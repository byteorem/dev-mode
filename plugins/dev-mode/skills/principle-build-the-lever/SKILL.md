# Build the Lever

On the third repeat, build a tool for it: a script, a query, a skill.

**Why:** repeated manual steps are slow and drift each time. A small tool is faster by the fourth run and does it the same way every time.

**Pattern:** notice the repeat, propose the tool in one line, build it small, keep it local unless asked otherwise.

**Anti-patterns:** a tool for a one-off; a framework where a ten-line script would do.
